# Derivations

Derive on paper before you code. One folder per phase (`phase1/`, `phase2/`, …).

- Scan or photograph your pages (PDF or JPG), or typeset them in LaTeX or Markdown with math.
- Each derivation ends with the exact equation the code implements, plus the file and function that implements it.
- If the code and the derivation disagree, one of them is wrong. Find out which before moving on.
